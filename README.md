# VerityCare AI 🛡️
### Evidence-First Healthcare Information, Dual-AI Verification & Doctor Discovery Platform

VerityCare AI addresses the critical hazard of confusing, misleading, or contradictory health advice generated by AI systems. Operating under the fundamental maxim that **medical evidence has priority over AI confidence, fluency, or model agreement**, the platform extracts discrete factual claims from independent AI models, validates them against peer-reviewed clinical guidelines, and facilitates doctor discovery with official council registration checks.

- **Node.js**: v18.0.0 or higher
- **Python**: v3.9+ (Python 3.10 recommended)

## 5. Environment & Model Configuration

Create your `.env` file from `.env.example`:

```env
# Optional Local Ollama runtime endpoint
OLLAMA_BASE_URL="http://127.0.0.1:11434"

# Independent Model Names
MODEL_A_NAME="llama3:latest"
MODEL_B_NAME="mistral:latest"

# Optional Cloud Verification Fallback (Stored strictly on backend)
GEMINI_API_KEY="YOUR_KEY"

# Optional Cloud Database Sync (Disabled by default, IndexedDB is primary)
MONGODB_URI="mongodb://localhost:27017/veritycare"
JWT_SECRET="veritycare_secure_local_dev_secret"
```

### Configuring Local Models in Ollama
Pull your preferred medical or open-source models:
```bash
ollama pull llama3
ollama pull mistral
# Alternatively:
ollama pull meditron
ollama pull biomistral
```
If Ollama is not active or a model is missing, VerityCare AI truthfully discloses the runtime state in the UI and seamlessly falls back to the configured backend verification engine or offline guideline pack.

## 6. Medical Claim Verification & Scoring Methodology

Model responses are compared using transparent, configurable weights:
1. **Evidence Accuracy & Guideline Adherence (60%)**: Highest priority factor. Heavily penalizes claims that contradict established clinical guidelines (e.g., pediatric aspirin, inappropriate routine antibiotics).
2. **Completeness & Red-Flag Coverage (15%)**: Evaluates whether essential warnings and symptoms were addressed.
3. **Clarity & Structure (10%)**: Readability, accessibility, and logical flow.
4. **Appropriate Uncertainty Handling (15%)**: Rewards prudent acknowledgment of medical limits and advising consultation with registered clinicians.

### Truthful Claim Statuses
- **Supported**: Directly matched to verified facts in accredited clinical resources.
- **Conflicting evidence**: Contradicts peer-reviewed consensus or official guidelines.
- **Insufficient evidence**: Statement requires individualized clinician evaluation or lacks conclusive literature evidence.
- **Not verified**: Technical service failure or unindexed assertion.

## 7. Balanced Doctor Discovery & Ranking

Doctors are ranked across 5 balanced criteria without fabricating reviews or credentials:
- **Specialty Relevance (35%)**: Direct alignment with patient symptoms or concerns.
- **Registration Verification (25%)**: Validated against National Medical Commission (NMC) or State Medical Councils.
- **Distance / Proximity (15%)**: Calculated when location or PIN code is provided with consent.
- **Appointment Availability (10%)**: Distinctly indicates verified slots vs. direct clinic contact.
- **Review Quality & Volume (15%)**: Review source and verified patient status are visibly attributed.

---

## 8. Privacy & Data Sovereignty

- **Local-First Default**: All user chats, uploaded report text, and symptom check-ins are saved exclusively to browser IndexedDB.
- **Zero Cloud Leakage**: Health records are never sent to external servers unless the user explicitly toggles the opt-in Cloud Sync feature in the History tab.
- **1-Click Export & Purge**: Export all records as a portable JSON file or permanently wipe all data in one click.
- **Sanitized Logging**: Server logs record only endpoint paths and timestamps; sensitive health queries and report contents are never logged.
